Noctalia loads `panel.luau`/`bar.luau`, the app (lupa) loads `app.luau`; `lib/ ui/ pages/ umbriel_settings.py` serve both → verify `plugin host`.

## Pages

- **Outputs** (`outputs.content` only: no entry list or Add box; `fill` while displays are drawn, so the canvas card takes the free height; tiles fit `PANEL_AREA` 880×490 in the 980×760 panel, the card's reported size in the app via `onResize`, sizes ≤ 0 ignored):
  - Tiles drawn to scale from `arrange.bands` with spacer boxes: tile `display-tile-<id>` → face `display-face-<id>` (fill `surface_container_highest/0.55`: Noctalia draws the floating copy at a fixed 96 %).
  - Only the middle (number + `grip-horizontal`) is the `ui.dragSource` `display-<id>` (`previewAncestor = 2`, `onClick` = open/create the entry): Noctalia's drag source puts its own input area over its subtree, nothing inside one gets clicks. Drag type `display:<id>`, every zone accepts only the other displays' types (`dragTypes`; Noctalia keeps the dragged tile in place at 28 % and doesn't skip its zones; one shared type past 16).
  - Four edge and four corner `ui.dropZone`s `display-<side>[-start|-end]-<id>` (corners in the top/bottom strips), `hitSlop = 1` (a zone inside a drag source's input area is only found through `hitSlop`), value `side|id`, via `ctx.dropHandler`. A drop writes every arranged display's position with one `entryOpsBatch`.
  - Top strip = clickable star `display-star-<id>` (filled `primary` on the default; a click makes it the default, on the default clears it: only that entry has `focus_at_startup = true`, plus `general.xwayland_primary_output` = its entry name, all in one `store.group`) + resolution; bottom = name.
  - No rows under the drawing (the user removed Default display/Move; Position fields are the non-pointer way, a tile opens with Enter in the app); **Tidy up**, Refresh, disabled displays and **Not connected** entries as rows; errors via `kit.retryNotice`.
  - A tile click on a display without an entry adds one and calls `ctx.markProvisional()`: leaving (any navigation, `onClose`) without another edit undoes the add.
  - Output detail page: no “Name for a copy”/Duplicate (effect presets and pools keep it), a name input (`label` op; GUI-only, `gui-labels.json` as `{"output": {name: label}}`; key carries `ctx.gen`), says “Display N” while connected; meta `picker = "mode"` (`meta.MODE_FIELDS`) → `fields.luau` `modeControl`: Resolution + Refresh rate selects from the matched live output (else a text box).
- **Pickers**:
  - Route `pick-live` {editor,index,kind} (`entries.luau`, shown when an editor has `match.app_id` → windows or `match.namespace` → layers; filter + 40 rows; app id + title in one `entryOpsBatch`).
  - Route `xkb` {editor?,index?} (`xkb.luau`, opened by **Choose…** on fields with meta `picker = "xkb"`, part in `field.xkb`; page fields found via meta, device entries via `spec.entry`; layout + variant written in one `store.group`, the variant only when it changes; empty lists unset the key).
  - Meta `names_from` (`curve`/`effect` from the schema `format`, `output` for `meta.OUTPUT_FIELDS`) → `store.namedChoices(kind, base, extra)` adds the config's names (kinds also `pool scratchpad workspace submap`; curves/presets/pools from include files via `state.included` = `umbriel_core/included.py`; outputs plus `ctx.liveOutputs()`, one table per answer so the cache hits) to the combo (effect and output fields become combos; choice `""` = “None” only where it is the default).
  - Keybind detail: `argumentPicker` fills the action's first argument by its catalog placeholder (unknown value shown “(not defined here)”).
  - Meta `picker = "file"` (`meta.FILE_FIELDS`: title, filter, start, relative, command) → **Browse…** (`fields.luau` `browseButton`; lists append; text/combo boxes are bumped to show the path) → `files.open(ctx, options, onChosen, replace)` (`pages/files.luau`, also user folders with `mode = "folder"`): app and plugin alike go to route `files` (no chooser windows: the panel would cover them) with `view.pick = {options, onChosen}`, `view.files` = listing from helper `list-dir` {path | start+config, filter, folders}: folders then matching files, no hidden ones, 2000 max; Up/Home/path box/filter, 40 rows; a file or **Use this folder** goes through helper `pick-file`/`pick-folder` {chosen, …}, which map it (relative to the config, `$HOME`, command; no `chosen` = cancelled), then `ctx.back()`. `command` (autostart): Browse… opens route `appPicker` kind `command` (the default-apps list; an app → helper `app-command` {id} = its desktop file's Exec without field codes, `mimeapps.app_path`/`exec_command`; **Browse files…** next to the search = `files.open(…, replace = true)`, so back returns to the form); a chosen `.desktop` file → its Exec, other files → `shlex.quote`d path; none → `code:"no_command"`. `ctx.clearPickerBusy()` on `onOpen`/`onRecover` (also drops a `view.files` mid-request).
- **Home**: `home.renderCustomized` = route `customized` (overridden page fields, capped 40); app Home = dashboard (config, `customizedRows` top 8, newest 3 backups, cached per config revision), panel Home = cards + footer.
- **Keybind sorting**: `ui.dragSource`/`ui.dropZone` (API 5/38) with `onDrop = "onDrop"`; payload/value `r|<row index>|<key>` or `g|<group index>|<name>` (0 = Ungrouped), checked against the list before moving; row onto row = before it, row onto group = its end, group onto group = before it; rows re-sorted into display order (`keybind_order.luau`: `sortRows`, `moveRow`, `moveGroup`, `drop`; = file order); off while filtering, no grip on locked rows; ↑/↓ buttons as the non-pointer way.
- **Tests**: open a keybind row with `H.clickShortcut(key)` (row key `kb-<index>-<key>`); drop with `H.drag(sourceKey, zoneKey)`.

Rules:

- Edit `python/umbriel_core/`, then `tools/sync_plugin_core.py`; never the copy. Desktop commands work without tomlkit.
- Field metadata (labels, kinds, defaults, ranges, choices, help, glyphs) only from `meta`; no field lists in Luau.
- 25 ms per callback (3 overruns disable the runtime): one open group per page (all closed when a page opens, app and plugin), capped lists (search 40, apps 40, MIME 50), big JSON in its own `readFileAsync` callback, `ctx.renderSoon()` for bursts.
- Inputs are uncontrolled: stable keys (`… .. ctx.gen(key)`), `ctx.bump(key)` to replace text; also key every container around an input that has optional siblings before it (unkeyed nodes are matched by position, so a badge appearing in front rebuilds the container and the input loses focus); `ctx.resetInputs()` replaces all of them (discard, save), `ctx.discardAll()` = store discard + diagnostics + inputs. Never assign `view.gen = {}`. Keys of per-entry inputs include the entry index. `onOpen` clears busy flags of requests the close dropped. `ui.select` is zero-based. Toggles, sliders, selects, color pickers need their value every render. Sliders go through `fields.luau` `slider()`: preview on `onChange`, commit on `onDragEnd`; Noctalia also calls the (previous render's) `onChange` when a render moves a slider, so a change without a running gesture at the last rendered value (`view.sliderShown`) is ignored, or typing in the number box would rebuild it. Never index a built node's `.children`.
- No context menus (the app has none): every action is a visible button.
- Syntax: Luau ∩ Lua 5.4/5.5 (checked by `luac -p` and `luau-compile --null`); every `.luau` starts with `--!nonstrict` (community-plugins convention, `test_panel.py` checks it). Colors: no retired roles (`outline` → `outline_variant`; `plugin:validate`). `cond and nil or x` is always `x`. Glyphs must exist in Tabler (`test_host_bridge.py`). Icon-only buttons need a `tooltip` (accessible name).
- Helper only via `lib/helper.luau` (argv array, JSON files); never shell strings. The helper validates and answers `{ok:false,error,code}`.
- Store edits go through the store setters (undo records them); never assign `store.desktop` values or keybind rows without `setDesktop`/`keybindsChanged`.
- Keep unrelated content, MIME fallbacks, revision checks, write lock, validation, backups (`backups.snapshot_file`, newest 10), atomic writes (`paths.atomic_write`), symlink refusal.
- Check the Noctalia API of the target release first (local Noctalia git cache; old notes: `git show 588a1bf:'noctalia-plugin/Noctalia API'`).
