Rules:

- Field metadata (labels, kinds, defaults, ranges, choices, help, glyphs) only from `meta`; no field lists in Luau.
- 25 ms per callback (3 overruns disable the runtime): one open group per page (all closed when a page opens, app and plugin), capped lists (`kit.LIST_CAP` 40: search, apps, files, XKB, open windows; MIME 50; action search 60), big JSON in its own `readFileAsync` callback, `ctx.renderSoon()` for bursts.
- Inputs are uncontrolled: stable keys (`… .. ctx.gen(key)`), `ctx.bump(key)` to replace text; also key every container around an input that has optional siblings before it (unkeyed nodes are matched by position, so a badge appearing in front rebuilds the container and the input loses focus); `ctx.resetInputs()` replaces all of them (discard, save), `ctx.discardAll()` = store discard + diagnostics + inputs. Never assign `view.gen = {}`. Keys of per-entry inputs include the entry index. `onOpen` clears busy flags of requests the close dropped. `ui.select` is zero-based. Toggles, sliders, selects, color pickers need their value every render. Sliders go through `controls.luau` `slider()`: preview on `onChange`, commit on `onDragEnd`; Noctalia also calls the (previous render's) `onChange` when a render moves a slider, so a change without a running gesture at the last rendered value (`view.sliderShown`) is ignored, or typing in the number box would rebuild it. Never index a built node's `.children`.
- No context menus (the app has none): every action is a visible button.
- Syntax: Luau ∩ Lua 5.4/5.5 (no `continue`, `+=`, types, backticks; checked by `luac -p` and `luau-compile --null`); every `.luau` starts with `--!nonstrict` (community-plugins convention, `test_panel.py` checks it). Colors: no retired roles (`outline` → `outline_variant`; `plugin:validate`). `cond and nil or x` is always `x`, `cond and false or nil` is always `nil`: use `if`. Tooltips only where `noctalia.d.luau` has them (not `ui.glyph`/`ui.slider`: wrap in `ui.row({tooltip})`). Glyphs must exist in Tabler (`test_host_bridge.py`). Icon-only buttons need a `tooltip` (accessible name).
- Helper only via `lib/helper.luau` (argv array, JSON files); never shell strings. The helper validates and answers `{ok:false,error,code}`. A request whose result must not get lost when the panel closes (saves, restores, deletes, set-config, Try) uses `always` and handles `not ctx.isOpen()`.
- Store edits go through the store setters (undo records them); never assign `store.desktop` values or keybind rows without `setDesktop`/`keybindsChanged`.
- Keep unrelated content, MIME fallbacks, revision checks, write lock, validation, backups (`backups.snapshot_file`, newest 10), atomic writes (`paths.atomic_write`), symlink refusal.
- Check the Noctalia API of the target release first (local Noctalia git cache; old notes: `git show 588a1bf:'noctalia-plugin/Noctalia API'`).
