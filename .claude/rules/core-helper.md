# Helper and core (`umbriel_settings.py`, `python/umbriel_core/`)

The app imports the helper in-process (`host/api.py` `runAsync`; `SLOW_HELPER_COMMANDS` on a 2-thread pool,
`LONG_HELPER_COMMANDS` (`wait-live`, `wait`) on a thread each); the plugin runs it with `python3`.

| File | Notes |
| --- | --- |
| `umbriel_settings.py` | `run(argv)` → stdout text (app calls in-process). Commands: `meta read preview (check: validate even unchanged) save set-config backups backup-diff restore trial-end delete-backups desktop desktop-save extension outputs windows layers xkb run-action focused-window wait-live wait kde-colors pick-folder pick-file list-dir app-command launch-app open-config set-editor about palette-template titlebar titlebar-cleanup` (`titlebar` per `config`, read-only). `outputs windows layers focused-window wait-live` map `umbriel` failures through `ask_umbriel` (here; readers in `umbriel_core/live.py`: one row per app id/namespace with an exact `pattern`; `wait_change(events, timeout)` reads `umbriel subscribe`, takes each event's first line as the baseline and answers on the first change of what a page shows (`_digest`), else null; `schema.run_umbriel` runs every `umbriel` call with `child_env()`; `schema.umbriel_executable()` finds it); `wait {seconds ≤ 5}` is a UI timer; `xkb` = `umbriel_core/xkb.py` catalog + `current`; `run-action` refuses `actions.run_block_reason` (checked on the `shlex` words, so quotes don't get past it; same lists in `meta.actions.blocked`, checked in `keybind_actions.luau` `blockReason` with quotes dropped) and runs `umbriel msg` (`msg_argv`: spawn keeps its command as one word, split off on any whitespace). `meta` has schema coverage, `targets` (`meta.UMBRIEL_VERSION`/`NOCTALIA_VERSION`; About shows them), per-page group help (`help.group_help`), labels without bracket notes (`help.split_label` → `unit special hint`, `restart`). `WRITE_COMMANDS` run under `paths.write_lock(data_dir)` (flock, 20 s; timeout → `code:"busy"`). `save {trial: seconds}` arms `umbriel_core/trial.py` before writing (token `<config dir>/trial.json`, 0600; an unexpired token → `code:"busy"`; arm-time deadline is only a fallback; `confirm` (backup, tried SHA-256, deadline seconds + `GRACE`) runs as `Session.save(before_write=...)` right before the write, so its failure writes nothing; `protect_pending` keeps `pending_backup` from `delete-backups` until the token's deadline + `GIVE_UP` (a token left by a watcher killed with the session protects nothing); a failed `confirm` raises OSError "…so nothing was tried"; the watcher = the module's own source run by the host `python3 -I -c` (never one inside `$APPDIR`; none → refuse), forks, `chdir("/")`, at the deadline takes the write lock (gives up after `GIVE_UP`) and restores `backup` unless the config's SHA-256 changed (a config still equal to the backup = confirmed but never written → `restored`); snapshots the tried file 0600 and prunes; writes `trial.result.json` {id, restored, reason}; `notify-send` via PATH) and returns `trial` (id); `restore {trial}` checks the token before the revision (gone → `code:"trial_over"` with `trial.describe(outcome)`), re-checks the revision after validation, claims only after the write (killed in between: the watcher finds the config equal to the backup, a no-op); `trial-end {trial}` (Keep, string required) → `ended` or `ended:false` + `message`. `save` also applies title-bar `follow` intents (`follow_intents`: `{source, alpha "XX"}` or false on `colors.title_bar.*` changes; after the write, failures are warnings) and `titlebar_theme.refresh_script()` under the lock. `save`/`restore` return `warnings` for failures after the write (`state` may then be null → reload); `restore` validates; `desktop-save` saves each part on its own (`{part: {revision}}`, `errors:{part}`); `desktop` reads each file on its own (`error` per part) and adds `apps.names` for hidden assigned apps. SIGTERM → `SystemExit` (temp files cleaned). Empty request may be `[]`. Unexpected exceptions → `{ok:false, code:"internal"}` |
| `lib/titlebar.luau` + `umbriel_core/titlebar_theme.py` | KDE/KDE header buttons + opacity on `colors.title_bar.background(_unfocused)` queue the palette color (`status().sources[field][source]` + alpha) with a store `follow` intent; only `save` calls `titlebar_theme.follow` → Noctalia user template `umbriel_titlebar` with one `# config: <path>` block per config (validated and symlink-checked before any write, script installed last); `post_hook` = `titlebar_apply.py <rendered>` (stdlib, copied to `~/.config/umbriel-settings/`; `SCRIPT_VERSION`: `refresh_script` replaces only lower versions, from `save`; old `<rendered> <config>` still works) reads the rendered file and writes each config under its own copy of `write.lock` (`$XDG_DATA_HOME/umbriel-settings`, 60 s), re-reads before replacing (changed → start over, 3 tries), hidden temp names, backup `*.titlebar.bak` always 0600 (Noctalia's umbriel template keeps `noctalia.toml` last, so an include can't win). Nothing follows any more, or `cleanup()` (helper `titlebar-cleanup`, plugin `onExit` disable; uninstall only best effort) → entry, template, rendered file, script, `*.titlebar.bak` removed, empty folder too. `noctalia_theme`: symlinked config refused before removing; `_write_config` refuses when Noctalia saved meanwhile |
| `paths`, `backups`, `legacy` | Private data: `private_dir`/`tighten_dir` (0700), `default_gui_data_dir` tightens the data dir (and returns the new dir after a lost rename race), `snapshot_file` writes 0600 via `atomic_write`, `write_text_file(path, text, mode)` (sidecars 0600), `atomic_write` creates missing dirs 0700; `legacy.migrate_data_dir` also runs `.private-v1` (`make_private`: old files 0600/dirs 0700, `*.titlebar.bak`) |

Rules:

- Edit `python/umbriel_core/`, then `tools/sync_plugin_core.py`; never the vendored copy. Desktop commands work without tomlkit.
- A new helper command: `COMMANDS` (+ `WRITE_COMMANDS` if it writes), `host/api.py` lanes if it waits, a reply or hold in `noctalia-plugin/tests/harness.lua` for UI tests, a case in `test_umbriel_settings.py` (fake `umbriel` in `support.py`).
- `legacy.migrate_data_dir` adopts rolling `.bak` files of releases up to 0.1.0-004; `paths.LEGACY_DIR_NAME` and the title-bar `OLD_*` paths cover 0.1.0-001…005.
